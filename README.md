# Abledsoul Portfolio

Neo-Punk / Shadow Architect portfolio for **Duane Marcel Abledsoul** — Navy veteran, award-winning filmmaker, extreme metal artist, published author, Wiccan high priest, and tech founder.

## Stack

- React 18 (CDN)
- Tailwind CSS (CDN)
- Single-file `index.html` — zero build step

## Aesthetic

Cinematic dark theme with neon/glow accents (cyan, magenta, purple, green). Font stack: Orbitron (display), Inter (body), JetBrains Mono (code).
